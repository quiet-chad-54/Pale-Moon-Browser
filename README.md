## 📖 About

Pale Moon is an open source web browser developed by the Pale Moon project team, derived from the Firefox codebase and rebased on the independent Goanna layout engine. It keeps the classic pre Australis interface, supports a large library of extensions, and offers deep customization for the toolbar, tab bar and status bar. The 2026 build includes refreshed media handling, updated TLS support and continued performance tuning for modern websites.

If you came looking for a Pale Moon Browser download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** users who prefer a classic browser interface · people running older or low-resource Windows PCs · extension power users · privacy-conscious browsing · dual-browser setups · developers testing Goanna rendering · anyone wanting a highly customizable UI

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway** |
| Installer stops without an error | Reboot Windows and run the setup file again from the Downloads folder |
| Browser will not start after install | Check for a pending Windows update, then reinstall over the existing copy |
| Pages render incorrectly | Clear the browser cache, then check the site with a fresh profile |
| Extensions fail to load | Confirm the add-on is compatible with the current Pale Moon build |
| Video playback stutters | Update your graphics driver and confirm hardware acceleration is enabled |
| Profile looks corrupted after a crash | Open the profile manager and create a new profile, then restore bookmarks from backup |
